# 贡献约定

生产代码位于 `src/core`、`src/host`、`src/agent` 和内部头文件目录 `include/msys_sandbox_compat`。可选 PSEC 工具位于 `tools/psec-run`。测试脚本在 `tests`，夹具在 `tests/fixtures`，独立单测在 `tests/unit`。

优先使用直接控制流和已有类型。宿主与 agent 使用不同选项编译共享代码。早期 agent 无 CRT、普通导入或 `DllMain`，二级线程上运行时使用 MSYS 管理的栈。

遵循[生产约束](design.md#生产约束)。原生 relay 只安装进程创建 hook。测试夹具可在标记目录上配置 ACL，作为初始策略。验收既要求工作负载成功，也要求原有限制继续生效。

英文为默认语言，简体中文文档放在 `docs/zh-CN/`。命令、行为、兼容范围或变更记录发生变化时，在同一次提交或 PR 中更新两种语言。保持 ADR 编号一致。重要决定有变化时新增 ADR，并链接到被替代的决定。

复现说明和证据链接使用读者可以取得的仓库或上游材料。构建产物位于 `build`，安装布局位于 `build/package`。全新检出应能独立构建。

按改动运行[相关回归](testing.md)，涉及多个运行机制或发布验收时使用完整矩阵。文档改动检查链接和命令示例。权限拒绝检查和相关工作负载一起运行。安装行为变化或有异常修改迹象时检查分发文件完整性。

提交按可独立理解和验证的改动组织。本机策略、生成输出和本地研究留在提交之外。
